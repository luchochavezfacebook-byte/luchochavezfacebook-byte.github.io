# TV FULL PRO — actualizaciones oficiales

Este repositorio publica únicamente el manifiesto de actualización de TV FULL PRO.

La aplicación y su código fuente permanecen en un repositorio privado separado.

Los avisos OTA solo se activan cuando ambas APK (ARM32 y ARM64) estén firmadas, verificadas y publicadas mediante enlaces HTTPS accesibles a las TV Box.
